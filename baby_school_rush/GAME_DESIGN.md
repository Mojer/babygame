# 上學衝衝衝～

遊戲設計 v0.1 · 2026-09-15

## 1. 一句話概念

背起粉色書包，穿過每天不同的上學路！玩家只用「跳躍、蹲下」，在可愛像素小鎮中閃避障礙、收集星星，最後跑進熟悉的校門。

這是一款有終點的 2D 橫向自動跑酷網頁遊戲，支援電腦、手機與平板。氣氛輕快、有一點趕時間的興奮感；碰撞以踉蹌、星星特效呈現。

## 2. 參考與設計範圍

依據使用者提供的兩段對話：「上學衝衝衝！ | 像素跑酷遊戲」與「上學衝衝衝，生成遊戲素材」，以及其中可讀取的角色參考照片。

沿用的核心設定：像素風、小學生上學、角色自動跑、上下兩種操作、背景／遊玩前景／UI 分層、每關終點都是學校、關卡更換地點與天氣時間。一般關卡以 60～75 秒為主，最後 8～12 秒開始看到學校。

以下生命、評星、關卡表、動畫尺寸與物理數值是本版新增設計提案，實作後需用試玩校準。本文件是設計規格，尚非可玩遊戲或已完成的素材包。

## 3. 核心循環

選擇路線 → 看見天氣與出發時間 → 倒數出發 → 跳／蹲閃避並收集星星 → 看見學校 → 跑進校門 → 獲得成績與貼紙 → 下一關或重玩。

首版包含一個主角、教學加三個正式關卡、選關、暫停、結算與本機進度。先完成第一關的整套體驗，再擴充路線。

## 4. 操作與角色狀態

| 操作 | 電腦 | 觸控 | 規則 |
|---|---|---|---|
| 跳躍 | ↑ 或空白鍵 | 點右下「↑ 跳」 | 單次固定高度跳躍；按住不連跳 |
| 蹲下 | 按住 ↓ | 按住左下「↓ 蹲」 | 地面縮小碰撞框；放開站起 |
| 暫停 | Esc | 右上暫停 | 暫停時間、物理、障礙與音效 |

- 角色保持在畫面寬度約 28%，向右奔跑，環境往左捲動。
- 第一版不設二段跳。空中按下蹲不急墜；落地時仍按住則直接蹲下。
- 蹲下時按跳躍會起跳，跳躍優先。落地前 120 毫秒內按跳可緩衝到落地執行。
- 切換分頁、失去焦點或觸控被取消時清除按鍵狀態並暫停；回來點「繼續」，倒數三秒恢復。
- 狀態：待機、跑步、跳躍、蹲跑、受擊、抵達、失敗。受擊無敵是額外旗標，期間仍可跳蹲。

### 初始手感參數

以 640 × 360 邏輯畫布為基準：跑速 220 px/s、重力 1,200 px/s²、起跳速度 −480 px/s，滯空約 0.8 秒、最高約 96 px。角色美術格為 64 × 64，站立碰撞框初估 24 × 48，蹲下 32 × 24，兩者腳底對齊。書包、頭髮末端不計入受擊框。

以上數值是調校起點。地面障礙優先控制在高 20～36 px、寬 24～48 px；高障礙下緣距地面約 32 px，讓蹲下能通過、站立會碰撞。組合必須依完整碰撞範圍驗證可解。

## 5. 成功、碰撞與獎勵

- 正式關卡有三顆愛心；每次碰撞扣一顆，短暫閃爍並無敵 1.5 秒。同一障礙只能扣一次。
- 碰撞不改變世界速度與關卡進度，避免固定路線節奏漂移。
- 愛心歸零顯示「再試一次，你可以的！」，可一鍵重開本關。
- 帶著至少一顆愛心穿過校門即通關。教學關碰撞只提示，不扣生命。
- 評星三個條件各一星：抵達學校、收集至少 70% 星星、全程無碰撞。重玩保留最佳評星。
- 通關解鎖下一關及一枚路線貼紙；貼紙僅作收藏。
- HUD 顯示生命、收集數、到校進度與暫停。出發時間用於情境，不額外設置隱藏遲到失敗條件。

## 6. 關卡規劃

| 關卡 | 主題與情境 | 時長 | 玩法重點 | 終點 |
|---|---|---:|---|---|
| 00 第一天出門 | 晴天巷口，07:20 | 40 秒 | 分段練跳、蹲；不扣血 | 學校 |
| 01 早安，小巷！ | 晴天住宅區，07:25 | 65 秒 | 花盆、三角錐、低樹枝 | 學校 |
| 02 雨滴奏鳴曲 | 雨天商店街，07:35 | 70 秒 | 水坑、遮雨棚；跳蹲交替 | 學校 |
| 03 風中的上學路 | 秋日公園，07:40 | 75 秒 | 滾動足球、低枝與節奏組合 | 學校 |

後續擴充：冬季車站街、霧中河堤、夕陽校慶。夕陽关設定為回校參加活動，讓時間與目的相符。下雨與落葉先作視覺變化，不直接改變角色摩擦力或跳躍手感。

### 第一關 65 秒配置

| 時段 | 場景 | 事件安排 |
|---|---|---|
| 0～8 秒 | 家門口 | 出發、少量地面星星；無障礙 |
| 8～22 秒 | 住宅巷弄 | 單個花盆、三角錐；練習跳躍 |
| 22～36 秒 | 小公園 | 低枝提示蹲下，穿插容易的地面障礙 |
| 36～53 秒 | 早餐店外 | 跳 → 落地 → 蹲，適度留出呼吸段 |
| 53～61 秒 | 校門前道路 | 校舍開始清楚可見，最後一組簡單障礙 |
| 61～65 秒 | 學校入口 | 無障礙星星路線，穿過校門 |

時間以正常遊戲進度計算，不含暫停與結算。第一關總路程初估 14,300 px；實際配置按角色與障礙的相遇時間安排。

### 排列原則

- 第一關障礙相遇間隔先採 2.4～3.0 秒；後續以組合增加難度，不單純加速。
- 第一個新障礙出現時，以圖示加短文字提示，至少保留 1.8 秒反應距離。
- 星星弧線提示跳躍軌跡；高障礙下方的低位星星提示蹲下。
- 首版使用固定可驗證的排列。避免同一時間要求跳與蹲，也避免尚未落地就必須穿過低棚。
- 移動障礙需預先出現在可視範圍，不從角色旁突然生成。
- 每段至少安排一次 3～4 秒無障礙空檔。終點前四秒不再扣血，讓抵達演出完整。

## 7. 美術方向

### 主角

以參考照片可見的黑色長髮、齊瀏海、粉色上衣、灰色裙裝、淺色鞋為基礎，加上使用者指定的粉色書包。採略大頭的可愛像素比例；側面朝右，跑步時頭髮與書包輕微擺動。

### 場景

台灣生活感的小鎮上學路：米白牆、鐵捲門、磁磚騎樓、早餐店、盆栽與路樹。角色粉色最鮮明，場景使用柔和米色、草綠與天空藍。障礙用清楚輪廓與明暗分離；可碰撞物不可與純裝飾使用難以區分的相同造型。

| 圖層（由後至前） | 內容 | 捲動倍率 |
|---|---|---:|
| 天空 | 漸層色塊 | 0 |
| 遠景 | 雲、山與城市輪廓 | 0.1～0.25 |
| 中景 | 房屋、商店、樹木 | 0.45～0.7 |
| 遊玩前景 | 地板、角色、障礙、收集物、校門 | 1.0 |
| 裝飾前景 | 畫面邊缘的葉片、矮欄杆 | 1.1 |
| UI | 生命、進度、按鈕 | 固定 |

裝飾不可遮住角色腳底、即將接觸的障礙或操作按鈕。遠景學校與終點校門使用不同呈現層級，確保最後進入同一所學校的方向連貫。

### 素材交付規格

| 分類 | 首版需求 | 規格起點 |
|---|---|---|
| 主角 | 待機 4、跑步 8、跳躍 6、蹲跑 4、受击 2、到校 6 格 | 每格 64 × 64、透明 PNG、固定腳底基準 |
| 地面 | 人行道、濕地、校園步道 | 32 × 32 可平鋪 Tile，檢查接縫 |
| 低障礙 | 花盆、錐桶、水坑、足球 | 每種獨立透明圖與碰撞框資料 |
| 高障礙 | 樹枝、遮雨棚 | 含清楚支撐關係的側視圖 |
| 背景 | 晴天住宅、雨天商街、秋日公園 | 分層圖，水平方向可循環 |
| 終點 | 校舍、校門、旗幟 | 拆件，校門位置需可作終點判定 |
| 收集與效果 | 星星、水花、腳步煙塵、撞擊星光 | 透明圖或小型動畫表 |
| UI | 愛心、星星、上下箭頭、暫停、貼紙 | 同一像素密度與描邊規則 |

動畫以時間驱動，跳躍影格對應上升、頂點、下降，不靠動畫結束決定落地。美術輸出需檢查透明邊緣、尺寸、對齊與色盤；生成式概念圖需經切圖和清理才能作為精靈圖使用。

## 8. 畫面與音效

- 標題頁：主角站在家門口，標題「上學衝衝衝～」，主按鈕「出發上學！」，次要入口「選擇路線」。
- 選關頁：以家 → 街道 → 學校的路線卡呈現，顯示天氣、最佳星等與貼紙。
- 遊戲頁：左上三顆心、中上到校進度、右上暫停；觸控按鈕放在遊玩區下方控制帶。
- 結算頁：「到校啦！」、星等、收集數與貼紙，提供「下一條路線」「再跑一次」。
- 設定：音樂與音效各自開關、減少動態效果；不以顏色或聲音單獨傳遞必要提示。
- 音效：短促起跳、落地、收集、碰撞與到校鈴聲；音樂在使用者開始遊戲後啟動。
- 橫向 16:9 遊玩區，像素採最近鄰取樣。手機直向時完整縮放遊玩區、保留上下按鈕，並提供橫向遊玩提示。觸控目標至少 56 CSS px，避開瀏海與底部手勢區。

## 9. 開發結構

承接原對話的 Phaser + TypeScript + Vite 方案；實作開始時再核對套件版本。核心用同一套 GameScene，關卡內容由資料決定。

- BootScene：資源載入、讀取音效偏好與存檔。
- MenuScene：標題、選關。
- GameScene：角色狀態、世界移動、障礙碰撞、收集與終點。
- ResultScene：星等、解鎖與重玩。
- LevelConfig：時長、速度、天氣、背景、場景分段、障礙事件、星星位置與學校出現點。
- SaveData：版本號、各關最佳星等、解鎖進度、設定，存於 localStorage；儲存失敗仍能遊玩。

關卡事件可記錄「預計相遇秒數」，轉成世界座標，確保鏡頭與障礙共用同一套距離基準。倒數、背景切換、校門位置和進度條都由關卡進度推導，避免各自計時造成不同步。

## 10. 製作順序與驗收

## 後續特殊道具：拔拔重機救援

神秘道具以極低機率出現在路線中。取得後播放拔拔騎重機登場的短演出，主角戴上安全帽坐上後座，畫面轉入自動衝刺並直接安全抵達學校。演出期間不再發生碰撞；本效果屬趣味獎勵，不影響正常通關所需能力。正式製作時需補重機側視圖、兩人乘坐動畫、安全帽、登場煙塵與校門停車演出。

### A. 第一關可玩原型

完成 65 秒固定路線、兩種操作、兩類障礙、三顆愛心、暫停／重玩與學校終點。使用能清楚分辨的暫用素材驗證手感。

驗收：鍵盤和觸控可各完成一輪；跳蹲碰撞框吻合；一次碰撞只扣一次；重玩重設狀態；背景分頁不偷走進度；53 秒看到學校，65 秒正常抵達。

### B. 正式美術與教學

替換主角動畫、分層背景、地板與校門，加入星星導引、40 秒教學、音效及結算。

驗收：初次玩家可理解高蹲低跳；動畫腳底不漂移；背景接縫不閃爍；手機按鈕不遮障礙。

### C. 擴充首版內容

加入雨天商店街、秋日公園、選關與本機存檔。

驗收：三關的背景、障礙節奏與情境有差異；所有組合可通過；達標的星等可保存；觸控中斷不會卡蹲；不同畫面更新率不改變跑速或關卡時長。
