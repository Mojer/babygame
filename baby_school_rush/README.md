# 上學衝衝衝～ · 第一關試玩版

Phaser 3.90 + TypeScript + Vite。使用 Node.js 22.12+ 或 24，建議 pnpm。

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

開啟終端列出的本機網址。部署時發布 `dist/` 內容；使用相對資源路徑，可放在 `/baby_school_rush/` 子目錄。不要直接開啟原始 index.html。

## V3 更新

目前限制為橫向遊玩；直向顯示旋轉提示並暫停。新滑行姿勢、角色固定尺度、DPR 繪製、世界座標與真正的前景／遠景分層已完成。前景、道路、障礙與校門以相同相機距離移動；遠景獨立慢速移動。詳細素材與提示詞見 `ASSET_UPDATE_V3.md`。

## 節奏組合更新

第一關加入六段固定組合：跳→蹲、蹲→跳、連續跳躍，後半再重複並加上最後節奏。畫面會在組合開始前顯示完整按鍵順序；成功越過障礙增加連擊，碰撞歸零，結算顯示最佳連擊。神秘道具「拔拔騎重機載到終點」已記入遊戲設計，尚未啟用。

## 素材與限制

`stuff/` 保留原始候選素材。`public/assets/` 存放遊戲使用的來源圖。Phaser 載入時定義與校準角色及障礙 frame，保留原始檔不動。

角色仍需正式動畫校準，跳躍、滑行與到校目前使用單張姿勢。場景已拆成視差層，地板局部重複仍可見。其餘正式關卡與 40 秒教學尚未實作。完整生成提示詞與後續素材清單見 `ASSET_UPDATE_V2.md`。
