# 桌上冰球大亂鬥 Air Hockey Mayhem

同一台平板／手機、上下對分的雙人桌上冰球。純 HTML / CSS / JavaScript（Canvas 2D），零相依套件。

- **兩人共用一個螢幕**：畫面上下對分，兩人各坐一邊，各用一根手指直接拖曳自己半場的擋板（絕對定位，手指在哪擋板就在哪）
- **大量冰球**：中央持續丟出冰球，每 14 秒一次爆量波，最多 30 顆（實際上限依場地面積換算，見下），六位手繪角色（`assets/`）輪流上場
- **限時 60 秒**：把冰球打進對面球門得 1 分，時間到分數高者獲勝，同分則平手
- **三種特殊技能**：吸鐵、關門放狗、鬧鐘。固定在自己那端的角落，各自冷卻，兩人都有（不用搶）
- **配樂即時合成**：全部由 WebAudio 算出來，不放音檔；最後 10 秒自動加快並加上滴答聲
- 手繪風介面：辰宇落雁體、筆記本紙張、抖動筆觸的球桌與手畫中圈

## 玩法

1. 平板平放桌上，兩人各坐短邊；**P1 在下方（藍）、P2 在上方（紅）**。
2. 手指按住自己那半邊拖曳擋板。擋板不能越過中線，也不會被推出牆外。
3. 冰球圓心越過對面門線才算進球，得分方 +1，該球移出場、中央再補新球。
4. 把球打進自己的球門也算對手得分，防守時小心別自己推進去。
5. 60 秒結束顯示結果（兩張卡，上面那張轉 180° 給對面看），可直接「再來一局」。

### 特殊技能

三顆技能鈕固定在**自己那端球門的一側**（P1 在畫面右下、P2 在畫面左上，對各自來說都是同一隻手邊）。
畫在 band 區、冰面之外，所以不會跟拖曳擋板的手指打架；命中範圍放寬到畫出來的 1.6 倍，手機上也按得到。

| 技能 | 效果 | 作用時間 | 冷卻 | 一局（60 秒）大約可用 |
|---|---|---|---|---|
| 🧲 吸鐵 | 把**全場**冰球往自己的擋板拉（1500 px/s²） | 3 秒 | 11 秒 | 4 次 |
| 🐕 關門放狗 | 把**自己的**球門封成柵欄，對手進不來 | 4 秒 | 13 秒 | 3 次 |
| ⏰ 鬧鐘 | 凍結全場：冰球、對手擋板、比賽計時全部停住，只有你能動 | 2.2 秒 | 22 秒 | 2 次 |

冷卻是**效果結束後才開始倒數**（所以吸鐵的完整循環是 3 + 11 = 14 秒）。

- 吸鐵是雙面刃：球會被拉到你的擋板附近，也就是你自己的球門前。
- 鬧鐘期間冰球的速度**原封不動保留**，解凍後接續原本的運動；你可以用擋板把球一顆顆推進對方球門。
  被凍住的人也不能按技能（他正停在時間裡）。
- 桌機測試技能：**P1 = `,` `.` `/`、P2 = `1` `2` `3`**。

桌機測試用鍵盤：**P1 = 方向鍵、P2 = W / A / S / D**。

## 實作重點

物理座標直接使用 CSS 像素（canvas 填滿安全區內框），因此手指座標不需任何換算，1:1 對應擋板位置。

**多點觸控**：`pointerdown` 依 y 座標決定歸屬（上半＝P2、下半＝P1），記住該玩家的 `pointerId` 後只認這根手指，其餘手指（手掌誤觸、旁觀者亂點）全部忽略；手指放開才釋放該半場。canvas 設 `touch-action: none` 關掉捲動與雙擊縮放。

**固定時間步**：物理以 1/120 秒定步進 + 累積器推進，單帧最多 5 步，因此 60Hz 與 iPad 120Hz 的手感一致，掉帧時也不會追爆。

**解算順序**（`stepPhysics`）：

1. 擋板以最大速度追向手指目標點（不直接瞬移，否則手指快速移動會把冰球推穿牆）
2. 冰球積分（冰面阻力、氣流微擾、速度上限）
3. 碰撞衝量：球對球等質量彈性碰撞、球對擋板視為無限質量的 kinematic 圓（吃到擋板揮擊速度，並保底出球速度避免黏板）
4. **位置鬆弛迭代**（上限 8 次，有早退，平常只跑 1～2 次）：擋板推開 → 牆面夾位置 → 球球分離。分離刻意排在最後，否則被擠到牆角的兩顆球會被牆面硬投影到同一點而完全重合
5. **擠爆逃生**：鬆弛後仍深度重疊，表示擋板把球壓進牆角、幾何上沒有可行解，改補一道正比於重疊深度的分離**速度**讓它們自己彈開
6. 門柱、牆面反彈與進球判定放在最後，保證每帧結束時所有冰球都在場內

固定亂數種子的量測顯示，鬆弛迭代超過 4 次就不再有任何改善（最差情況固定是兩顆球完全重合），因為那種配置真的無解——所以第 5 步不是優化而是必要。死壓角落 60 秒的最深重疊因此從 52px 降到 7.7px。

擋板把冰球壓在牆上時無解可循，`pushOutOfPad()` 會沿牆面求圓交點（x 貼牆解 y、y 貼牆解 x 共四組），取離原位最近的可行解，讓球一次就滑出來而不是靠迭代慢慢擠。

**氣流**：速度低於 90 px/s 的冰球會被氣流重新吹動，維持在最低速度以上，免得停成打不到的死球。方向沿用它自己的行進方向（完全停死才隨機），刻意**不吹向場中央**——那會把所有慢球吸成一坨黏在中圈；只有已經貼在牆邊的球會被往場內帶一點。

**撞牆判定用「貼到牆且速度朝著牆」，不是「穿進牆裡」**：這是冰球會黏在左右外框的真正原因。第 4 步的位置鬆弛會先把穿牆的球夾回牆面，等跑到第 6 步時已經看不到穿透，速度於是永遠不會被反彈——球被永久壓在牆上，靠切向速度一路滑。修正前實測有 **44% 的時間**冰球是真的貼著側牆（<2px），但 90 秒只有 109 次撞牆事件；平均一次黏 6 秒，最久 26 秒。改成用接觸判定後，貼牆時間降到 **0.6%**、平均一次 0.17 秒、超過 3 秒的情況從 213 次降到 1 次。

配合兩個附加規則：反彈時加上 ±10° 隨機偏角（反正牆是手繪歪線），以及**保底離牆速度** `WALL_KICK_MIN`（= 球徑 × 5.5）。後者是必要的，因為牆面反彈只衰減法向分量、切向完全保留，撞幾次之後軌跡會貼平在牆上，此時法向速度趨近 0，光靠偏角推不開。

> 附帶影響：冰球不再躲在牆邊，就會確實被打進球門，**消耗速度大約快一倍**（先前場上球數看起來多，有一部分其實是靠這個 bug 卡在牆邊不動）。因此生成間隔一併從 2.6→1.1 秒調整為 1.3→0.45 秒（局長改 60 秒、且鬧鐘凍結期間會暫停生成，都要一起算進去），場上平均球數才回到 10～19 顆。若覺得比分太高，調慢 `SPAWN_START` / `SPAWN_END` 或縮小 `GOAL_RATIO` 即可。

**技能如何接進物理**：鬧鐘用一個 `state.freezeBy` 旗標貫穿 `stepPhysics` —— 凍結時跳過積分與所有**速度**相關的步驟（碰撞衝量、擠爆逃生、撞牆反彈），只保留**位置**鬆弛與收束。因此施放者的擋板仍能把球推開（位置解算），但沒有任何速度被改寫，解凍後場上運動完全接續。關門放狗則讓球門開口在位置鬆弛與收束兩處都改當成牆（`goalOpen(side)`），而且只保護自己那側。

**冰球上限依面積**：固定顆數在橫向會讓覆蓋率從 8% 衝到 12%（場地面積小很多），球就開始互相卡。改成由 `F.w * F.h` 換算，四種尺寸都穩定在 7～8%。

**牆的筆觸**畫在場地外側半個線寬處，筆觸內緣才等於物理邊界，冰球才不會看起來壓進牆裡半顆。

**效能**：角色球與擋板都預先繪製成離屏 sprite，主迴圈只做 `drawImage`（避免每帧算漸層與陰影）。30 顆球的物理約 2–3 ms／模擬秒，60fps 下每帧約 0.05 ms。

## 資源

- 角色圖 `assets/ch_0*_s.png` 與 `babyballrace2` 相同，各自複製一份以維持每款遊戲獨立可部署
- **音效與配樂都是 WebAudio 即時合成**（`music.js`），整個資料夾沒有任何音檔，無授權問題。
  配樂走 I–V–vi–IV 四小節和弦進行（126 BPM，三角波主旋律 + 柔和鼓點），
  旋律從當下和弦音與五聲音階裡挑，每一圈 loop 換一次亂數種子，
  所以會一直長出新句子而不會聽到接縫。
  排程用 lookahead scheduler（`setInterval` 每 25ms 補排 120ms 內的音），不依賴 `requestAnimationFrame`，
  分頁掉帧也不會走音。`MUSIC.renderOffline(秒數)` 可離線算出音訊做自動化檢查。

### 字型（改文案的話請讀這段）

`fonts/chenyuluoyan-sub.woff2` 是[辰宇落雁體 2.0](https://github.com/Chenyu-otf/chenyuluoyan_thin)（SIL OFL 1.1，
Thin 2.100）的**子集**，只收本遊戲實際用到的 235 個字元，81KB。

子集是「照著文案裁的」，所以**只要改了畫面上的文字，就必須重新產生子集**，
否則新字會掉回系統字型（PingFang），畫面上會看到一段手寫、一段黑體的混搭。
初版直接沿用 `babyballrace2` 的子集就踩到這個坑——那份是照那款的文案裁的，
連本作標題的「冰」「鬥」都缺。重建方式：

```sh
cd babyhockey
curl -sLO https://raw.githubusercontent.com/Chenyu-otf/chenyuluoyan_thin/main/ChenYuluoyan-2.0-Thin.ttf
python3 tools/subset-font.py ChenYuluoyan-2.0-Thin.ttf   # 就地覆蓋 fonts/ 內的子集
```

工具會自動從 `index.html` 與 `*.js` 的字串字面值收集用字，若有連完整字型都沒有的字會
明確報出來（例如 `″` U+2033 就不在字型裡，計時因此改用「秒」）。完整字型 9.5MB，不進版控。
