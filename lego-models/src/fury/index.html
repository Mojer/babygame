    可實拼驗證

    • 零件來源：每個零件都對照 LDraw 官方零件庫（2025 版，約 2.5 萬個零件檔）確認存在，位置與方向用零件的真實幾何計算，3D 畫面顯示的也是真實零件外形。
    • 碰撞檢查：以真實外形的定向包圍盒逐一比對全部零件，0 處互相穿插（軸穿孔、齒輪咬合、輪胎套輪框屬正常接合，不計入）。
    • 接合檢查：787 個有凸點的零件，每一個上下都至少接到另一個零件，0 個懸空。
    • 機構尺寸：24T／24T 中心距 3 格、20T／28T 差速器 3 格、蝸桿對 60T 轉盤 4.25 格、避震器跨距 6.5 格，皆依 LEGO 齒輪半徑計算。
    • 仍需在 Studio 確認：側裝（SNOT）的防沙邊條與車首木樑支架、原木內部的軸、Hub 與馬達的固定方式、Technic 銷是否真的卡進孔，以及編織繩的實際繞法；這些在 LDraw 裡位置正確但接合方式需要你在 Studio 用穩定性檢查再確認一次。
    • 與上一版不同：依零件庫實測，履帶 57518 是 5 格寬單排，因此每個負重站改為單輪；FURY 貼紙不是 LEGO 零件已移除；綁帶改用 LEGO 編織繩 14225。

    把下面的內容存成 FURY.ldr，用 BrickLink Studio 開啟。每個零件的位置與方向都是用 LDraw 零件庫的真實幾何算出來的，開啟後應該直接到位；切換配色會一併更新這份清單。
