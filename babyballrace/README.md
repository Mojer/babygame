# Ball vs Ball 滾珠大作戰

直式手機網頁雙人滾珠競速遊戲。純 HTML / CSS / JavaScript（Canvas），零相依套件、零外部資源。

## 玩法

1. 玩家 1 與玩家 2 輪流從 5 顆造型球（烈焰、深海、雷霆、幻影、鋼鐵）中各選一顆，其餘 3 顆成為中立球。
2. 開始後 5 顆球同時從起點落入賽道，一路經過漏斗、之字斜坡、彈釘陣、彈力器、旋轉風車與 S 型窄道。
3. 球與球、球與環境都會互相碰撞。
4. 比賽中每位玩家有 3 次「加速」機會（螢幕左右下角按鈕；桌機可用 `A` / `L` 鍵）。
5. 第一顆抵達終點的球就是冠軍（＝排名第一）：是玩家的球則該玩家獲勝，是中立球則平手。

## 執行

任何靜態伺服器即可：

```sh
cd babygame
python3 -m http.server 8642
# 瀏覽器開啟 http://localhost:8642
```

建議以手機直式畫面（或瀏覽器行動裝置模擬）遊玩。

## 檔案

- `index.html` — 畫面結構（選球 / 比賽 / 結果三個畫面）
- `style.css` — 版面與 UI 樣式
- `game.js` — 球造型繪製、賽道定義、物理引擎（重力、膠囊/圓形碰撞、風車、彈力器）、音效（WebAudio 合成）與遊戲流程
