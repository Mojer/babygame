# Ball vs Ball 滾珠大作戰 2（單螢幕全覽版）

直式手機網頁雙人滾珠競速遊戲，`babyballrace` 的續作。純 HTML / CSS / JavaScript（Canvas），零相依套件、零外部資源。

與一代（長賽道、攝影機捲動）的差異：

- **整張地圖單螢幕全覽**：等比縮放置中，全程一眼看完，不捲動
- **資料驅動地圖**：賽道定義在 `maps/*.js`，新增關卡不用動引擎
- 支援手繪草稿圖作為關卡背景、每張地圖可自訂重力

## 玩法

1. 玩家 1 與玩家 2 輪流從 5 顆造型球（烈焰、深海、雷霆、幻影、鋼鐵）中各選一顆，其餘 3 顆成為中立球。
2. 開始後 5 顆球同時從起點落入地圖，經過漏斗、彈釘陣、旋轉風車、之字斜坡與彈力器。
3. 球與球、球與環境都會互相碰撞。
4. 比賽中每位玩家有 3 次「加速」機會（螢幕左右下角按鈕；桌機可用 `A` / `L` 鍵）。
5. 第一顆抵達終點的球就是冠軍（＝排名第一）：是玩家的球則該玩家獲勝，是中立球則平手。

## 執行

任何靜態伺服器即可：

```sh
cd babygame
python3 -m http.server 8642
# 瀏覽器開啟 http://localhost:8642/babyballrace2/
```

建議以手機直式畫面（或瀏覽器行動裝置模擬）遊玩。

## 地圖

選球畫面可直接切換地圖後遊玩。目前內建：

- `overview` 經典全覽 — 直式長圖：漏斗、彈釘陣、風車、之字坡、彈力器
- `sketch` 手繪迷宮 — 依手繪草稿編譯：右上進場、三層橫牆迷宮、左下終點

## 地圖格式（資料驅動）

地圖資料放在 `maps/*.js`，一個關卡一個檔案，只有座標資料、沒有程式邏輯。
新增關卡：複製 `maps/overview.js` 改名並修改資料，在 `index.html` 加一行 `<script>`，
選球畫面就會自動多出該地圖的選項（網址帶 `?map=關卡名` 可指定預設）。

欄位說明見 `maps/overview.js` 檔頭註解。`background` 欄位可放手繪草稿圖，會鋪在地圖底層。

### 手繪草稿 → 地圖（開發流程）

畫新關卡草稿時建議的標記約定，方便轉成地圖資料：

- 粗實線 = 牆
- 小圓點 = 彈釘
- 大圓圈加驚嘆號 = 彈力器
- 一條線加旋轉箭頭 = 風車
- `S` = 起點、`F` = 終點線
- 紙張直式，比例約 1:2（遊戲內邏輯尺寸 720 x 1440）

把草稿拍照傳給 Claude，由 Claude 轉成 `maps/xxx.js` 資料檔，草稿圖本身可作為關卡背景。

## 檔案

- `index.html` — 畫面結構（選球 / 比賽 / 結果三個畫面）
- `style.css` — 版面與 UI 樣式
- `game.js` — 球造型繪製、物理引擎（重力、膠囊/圓形碰撞、風車、彈力器）、音效（WebAudio 合成）與遊戲流程
- `maps/` — 地圖資料檔（資料驅動，一關一檔）
