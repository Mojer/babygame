# 上學衝衝衝 V2 — Framework Brief

## 一句話

兩鍵操作的高速橫向動作跑酷：玩家用最後一刻閃避累積 RUSH，在遲到前穿越三層城市路線衝進學校。

## 核心循環

```text
讀障礙 → 選上下路線 → 貼近閃避 → Perfect → Combo／RUSH
→ 高速爆發 → 喘息 → 場景事件 → 終點衝刺
```

## 操作語意

| 輸入 | 地面 | 空中 | 平台 |
|---|---|---|---|
| Jump | 跳躍 | 二段跳 | 跳往上層 |
| Slide | 滑行 | 急降 | 下穿單向平台 |

## Vertical Slice 節奏

| 進度 | 狀態 | 目的 |
|---:|---|---|
| 0–16% | Calm | 學會兩鍵 |
| 16–38% | Build | 開始上下路線選擇 |
| 38–58% | Fast | 連續 Perfect 機會 |
| 58–72% | Breath | 降低密度、重新讀圖 |
| 72–90% | Event | 平交道追逐段落 |
| 90–100% | Final Rush | 校門前衝刺 |

## 視覺規則

- 角色與障礙始終銳利；速度感由視差、鏡頭、殘影與局部速度線提供。
- 角色前方 35–45% 保持低背景對比。
- 角色色彩預算 100%，障礙 70%，遊玩地形 50%，中景 20%，遠景 10%。
- 平常畫面安靜，RUSH 才釋放最大動態與對比。
