# 女學生 Spine Setup Pose V1

## 母版素材

`schoolgirl-setup-pose-v1.png` 是 1024 × 1536、帶真正透明背景的 Setup Pose
母版。它用於重建分層 PSD 及核對角色組裝位置，本身不是分層檔案。

## PSD 畫布與原點

- PSD 維持 1024 × 1536。
- 角色位置及比例必須與母版相同。
- Spine Root／骨盆初始參考位置為 `(512, 805)`。
- PSD 匯入前不要個別裁切圖層。
- 所有旋轉關節底下保留部件長度約 10–15% 的重疊區。
- 不可以只切可見像素；被衣服或其他部件遮住的形狀也要補畫完整。

## 建議製作順序

1. 匯入分層 PSD 或逐張放入 27 個 PNG 元件。
2. 建立 Root、骨盆、脊椎、胸部、頸部與頭部骨骼。
3. 先建立後側手腳，再建立前側手腳。
4. 加入兩個腳部 IK Target，測試 Contact 姿勢是否滑步。
5. 頭髮、裙子與肩帶建立簡單 Mesh。
6. 先完成身體跑步循環，再加入頭髮、裙子及書包的次級動態。

完整骨骼座標與 Slot 順序位於 `schoolgirl-rig-plan-v1.json`。
