# 寶寶地球保衛戰（Baby Earth Defense）

直式手機射擊遊戲：戰機只能繞著地球公轉，自動朝外射擊，保護地球不被外星怪物撞擊。Phaser 4.2.1、TypeScript、Vite。

```sh
pnpm install
pnpm dev      # 網址加 ?boss 直接進 Boss 戰；?weapon=chain|laser|nova|spread 開局即持有該武器
pnpm test     # 遊戲邏輯測試
pnpm build
pnpm spec     # 由 src/game/assets.ts 重新產生 ASSET_SPEC.md
```

## 玩法

- **轉向**：按住／滑動畫面任何位置，戰機沿軌道轉向手指方位（鍵盤 ← →）。放開即停。
- **射擊**：自動連射，朝外太空方向。
- **炸彈**：右下按鈕（空白鍵），清除全畫面敵人與子彈、對 Boss 造成傷害。每擊破 40 隻怪物充能 1 顆，最多 3 顆。
- **失敗條件**：只有地球護盾歸零才會輸。戰機被撞只會暈眩 1 秒（停火、轉向變慢）。

## 敵人

| 敵人 | 行為 |
|---|---|
| 紅色大嘴怪 | 直線（微擺動）衝向地球，1 HP |
| 多眼怪 | 停在約 400px 外繞圈並發射可擊落的子彈，3 HP，擊破分裂為 2 隻小多眼怪 |
| Boss 觸手眼魔 | 沿畫面邊緣漂移。8 顆觸手眼球會射擊，本體此時無敵；眼球全滅後張嘴 9 秒露出核心，未擊敗則再生 4 顆眼球。會定期吐出大嘴怪 |

## 武器

| 武器 | 效果 | 持續 |
|---|---|---|
| 光束砲 | 預設，單發連射 | — |
| 散射彈 | 三向射擊 | 10 秒 |
| 雷電鏈 | 命中後電弧跳向附近最多 4 個敵人（含 Boss 眼球） | 10 秒 |
| 貫穿雷射 | 持續光束，打穿整條直線上的敵人與敵彈 | 7 秒 |
| 連鎖爆破 | 擊破的敵人延遲一拍爆炸，炸死的敵人再爆炸，最多 6 層 | 10 秒 |

- 道具膠囊：擊破時 9% 掉落，另外每個波次保證掉落一次展示武器（1-1 雷電鏈、1-2 雷射、1-3 連鎖爆破）。膠囊靠近戰機會被磁吸。
- 同種武器再撿到會延長時間。雷電鏈與連鎖爆破在 0.6 秒內連續擊破 3 隻以上會觸發「CHAIN ×N」。

## 音樂與 Motion Graphic

- `src/audio/music.ts`：WebAudio 即時合成 140 BPM 配樂（底鼓、軍鼓、Hi-hat、側鏈抽吸貝斯、琶音、Pad、Boss 主旋律），依段落切換：選單／波次／喘息／警報／Boss／弱點暴露／結算。擊破音沿 A 小調五聲音階依連擊上升。
- 音樂時鐘同時驅動畫面：`pollBeats()` 回傳已響起的拍子，`src/fx/motion.ts` 用它讓網格、波紋、軌道刻度、敵人、地球與 HUD 同步脈動。
- 打擊感：hit-stop（瞬間停格）、相機縮放衝擊、震動、斜條紋橫幅標題。

## 結構

| 檔案 | 內容 |
|---|---|
| `src/game/content.ts` | 所有數值與關卡波次資料（調難度改這裡） |
| `src/game/model.ts` | 純邏輯模型（不依賴 Phaser），固定 60Hz 步進，以事件通知渲染層 |
| `src/game/assets.ts` | 美術資產清單＋佔位圖繪製＋規格來源 |
| `src/main.ts` | Phaser 渲染、事件特效、輸入與 HTML HUD |
| `src/fx/motion.ts` | 節拍同步的 motion graphic 圖層與武器特效 |
| `src/audio/music.ts` | 合成配樂、音效與節拍時鐘 |
| `src/assets/` | 正式美術放這裡，檔名對應 `ASSET_SPEC.md` |

- 平衡設計：敵人以「抵達地球的秒數」定義速度，直式螢幕上下與左右來的敵人一樣公平。
- 畫面縮放：基準 1080×1920，`Scale.EXPAND` 依手機比例延伸，地球永遠在正中央。
