# 寶貝遊樂場 茜の篇：30 秒形象影片

1920×1080、60 fps、**128 BPM，64 拍 = 30 秒**。兩小節（8 拍）一個鏡頭。
畫面和音樂都只看 `score.json` 裡的拍點：`frame → beat = f / 60 / (60/128)`，`sample = beat × 60/128 × 48000`，所以兩邊不會對不上。

## 動態圖形規則

- 背景：各場景有自己的底色和花紋，包括放射光、圓點、斜紋、棋盤格、泡泡。上面有 26 個加了咖啡色描邊的圖形（星星、愛心、花、雲、圓環…），跟著節拍跳：一半在正拍放大，一半在反拍放大，每拍還會轉 1/8 圈並回彈
- 3D：直接載入遊戲的 `public/models/room_*.glb` 和 `char_*.glb`，用同一套卡通著色和咖啡色外框。畫布背景是透明的，讓立體場景浮在動態背景上
- 茜：`akane.ts` 用基本形狀組出來，兩頭身，茜色洋裝，頭上兩個包包頭綁紅緞帶。零件命名照遊戲規則（`akane_leg_L` 等），走路、眨眼、跳躍都跟其他角色共用同一套程式動畫
- 走路：每個八分音符踩一步（走路相位 = 2π × 拍數）
- 字體：jf open 粉圓（和遊戲選單同一款），白色內框 + 咖啡色外框 + 陰影

## 配樂（`audio.py`，全部用程式合成）

F 大調、128 BPM：烏克麗麗刷弦（Karplus-Strong 撥弦合成，正拍往下刷、反拍往上刷）、音樂盒鐵琴主旋律、「嗡–啪」貝斯、軟的四拍大鼓（會壓低其他樂器）、2、4 拍拍手、十六分音符沙鈴。
開場的旋律和標題字同步往上爬；好朋友段落每 2 拍換一個和弦，配上每位角色的「嗨」；進好朋友和片尾前有拍手滾奏。
音效（啵、彈簧、滑哨、小鴨吱吱、叮、水花、咻）都放在 `score.json` 的事件拍點上。響度約 -15.5 LUFS，峰值 -5.4 dBFS。

## 重做步驟

```bash
python3 audio.py                         # → out/soundtrack.wav
```

1. 啟動 `.claude/launch.json` 的 `playhousepromo`（Vite，port 5212）和 `playhousepromo-sink`（收畫格，port 5213）
2. 預覽：`http://localhost:5212/promo/`（有播放鍵和拖曳條，`?beat=12.5` 可以直接跳到某一拍）
3. 輸出畫格：`http://localhost:5212/promo/?render` → `out/frames/0000–1799.png`
4. `sh build.sh` → `out/baby-playhouse-akane-promo-1080p.mp4`

檢查單張畫面：在預覽頁的 console 執行 `snap([4.5, 10, 17])`，會存到 `out/snaps/`。
