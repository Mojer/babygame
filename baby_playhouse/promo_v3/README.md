# 寶貝遊樂場 茜と宇の篇（30 秒）

新角色「宇」加入的宣傳影片。沿用 `../promo_v2` 的 KIRAKIRA 普普風（彩虹通道、網點、漫畫貼紙、閃亮星星），一樣是 128 BPM、64 拍 = 30 秒、每 8 拍一個鏡頭。角色和場地直接用遊戲最新的模型（`char_yu.glb`、`room_farm.glb`、`room_ballpit.glb`），腮紅隱藏。

| 拍 | 鏡頭 | 內容 |
|---|---|---|
| 0–8 | 開場 | 茜和宇並肩從彩虹通道跑出來，第 2 拍抵達，各自說一句話；標題逐字出現，第 6 拍出現「茜と宇の篇」緞帶 |
| 8–16 | 新朋友 | 漫畫格介紹「小宇」（第 9 拍落地，NEW! 貼紙）；第 12 拍茜掉到他旁邊，說「一起玩吧！」，兩人一起跳 |
| 16–24 | 🌳 草坪 | 宇繞著溜滑梯追茜跑一圈半；20.5 拍茜爬上去，21 拍溜下來；宇跟著上去，22 拍溜下來；23 拍「抓到了！」 |
| 24–32 | 🌻 開心農場 | 宇在門口歡迎大家，朋友每半拍走進來一位；28–30 拍蘿蔔、高麗菜、番茄、南瓜、西瓜依序冒出來；30.5 拍「大豐收！」 |
| 32–40 | 🎈 球池房間 | 茜跳進球池，彩色球噴出來；宇在彈跳床上每拍跳一下；37 拍飛撲進球池，38 拍「噗通！」 |
| 40–48 | 快速巡禮 | 每 2 拍換一間：客廳看電視、咖啡廳、一起泡澡、搖搖馬和小汽車 |
| 48–56 | 大家一起 | 六位角色每半拍輪流跳；「和好朋友／一起玩！」；兩次歡呼 |
| 56–64 | 片尾 | 彩虹通道 + 雷射，六位角色掉到舞台，Logo、緞帶、「一起來玩吧！」 |

## 重做步驟

```bash
python3 audio.py                       # → out/soundtrack.wav
```

1. 啟動 `.claude/launch.json` 的 `playhousepromo`（Vite，5212）和 `playhousepromo3-sink`（5215）
2. 預覽：`http://localhost:5212/promo_v3/`（`?beat=20` 直接跳到某一拍；console 執行 `snap([…])` 存靜態畫面到 `out/snaps/`）
3. 輸出畫格：`http://localhost:5212/promo_v3/?render` → `out/frames/0000–1799.png`
4. `sh build.sh` → `out/baby-playhouse-akane-yu-1080p.mp4`
