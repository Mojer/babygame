# 怪獸單字防衛隊

無建置依賴的直式英文聽力遊戲。由寶貝遊戲首頁進入，或以 HTTP 伺服器開啟本目錄的 index.html。

- 六個年級練習詞庫；小一包含字母與簡單單字，之後逐級增加詞長與抽象程度。非特定教材課綱。
- 炸彈外框依單字的實際顯示寬度伸縮，較長單字會自動縮小字級，確保文字完整顯示且不換行。
- 每波輪流朗讀空中單字，點擊當前朗讀單字得 100 分；點錯會引爆並移除炸彈，向下散射 5 顆彈藥，每顆擊中城市扣 1% 防護，合計 5%，不扣分。
- 所有漏接炸彈產生火光與飄散煙霧，扣 5% 城市防護，防護歸零結束。每 15 秒提高波次並發出怒吼，增加堆疊炸彈與下降速度。
- 閃電連鎖清除當前朗讀單字的所有炸彈，顯示連線並正常計分，冷卻 18 秒。
- 支援暫停、切換分頁自動暫停、重玩、各年級本機最高分。
- 英文發音使用裝置 Web Speech API，需瀏覽器與英文語音支援。音效使用 Web Audio，沒有外部服務依賴。
- 背景音樂使用 `assets/word-defense-bgm.mp3`，以 12% 音量循環播放；英文朗讀時自動降至 1.8%，暫停或結束遊戲時同步停止。
- 支援時於手機全螢幕鎖定直式；不支援時以直式布局與橫向轉直提示替代。

已驗證 JavaScript 語法、遊戲狀態流程，以及 375 × 667 與桌面瀏覽器版面。裝置實際語音與方向鎖定仍須在目標手機確認。
